# Software Development

::: warning Washington-specific Modification

Teams must finish their entry by the early-entry deadline and submit their code. There is no semifinal round at the State conference; teams sign up for a presentation time.

:::

Using leadership and 21st century skills, participants apply knowledge of cutting-edge technologies and algorithms to design, implement, test, and document a software development project. The project should have educational or social value.

## Theme

Develop a software application that improves how people learn, teach, practice, or develop new skills. Identify an educational or training challenge and design an engaging, effective, user-centered solution.
