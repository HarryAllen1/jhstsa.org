# Architectural Design

::: warning Washington-specific modification
Washington requires an early-entry portfolio submission on March 18, 2027, and a qualifying virtual competition on January 21, 2027. See the [WTSA event page](https://www.washingtontsa.org/high-school-events/architectural-design) for submission instructions and state deadlines.
:::

In response to the annual design challenge, participants develop a set of architectural plans and related materials, and construct both a physical and computer-generated model to accurately depict their design. Semifinalists deliver a presentation and participate in an interview.

## Theme

For 2026–27, design a family-themed restaurant. See the [WTSA design challenge](https://www.washingtontsa.org/high-school-events/architectural-design) for the current Washington prompt.
